# Analytics & Knowledge Discovery

Solutions for the exercises from the **Analytics & Knowledge Discovery** course at **FH Salzburg**.

The `src` folder contains the solutions for the individual exercises. Each exercise has its own directory. For example, `src/E1` contains the notebook solution for the first exercise.

## Structure

```text
src/
├── E1/
│   └── ...
├── E2/
│   └── ...
└── ...
```

Each exercise directory contains the corresponding solution notebooks.
